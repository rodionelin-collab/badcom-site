# Приём заявок с сайта badcom.ru

Небольшой сервис на Node.js 22 без внешних пакетов. Форма на сайте отправляет заявку на `/api/zayavka`. Сервис:

1. проверяет данные и отметку согласия;
2. сохраняет заявку в файл на вашем сервере (`DATA_DIR/zayavki.jsonl`, доступ только у владельца);
3. отправляет письмо на `MAIL_TO` (info@badcom.ru);
4. отправляет уведомление в Telegram;
5. раз в сутки удаляет заявки старше `RETENTION_DAYS` дней (30), как обещано в Согласии.

Если почта или Telegram не работают, заявка всё равно сохраняется в файл, посетитель видит «Заявка отправлена».

## Установка на сервер (для администратора)

1. Скопировать папку `server` на сервер, например в `/opt/badcom-zayavki`.
2. Скопировать `.env.example` в `.env` и заполнить. Права: `chmod 600 .env`.
3. Запуск: `node --env-file=.env zayavki.mjs` (нужен Node.js 22 или новее).
4. Чтобы сервис работал постоянно, создать службу systemd `/etc/systemd/system/badcom-zayavki.service`:

```
[Unit]
Description=Заявки badcom.ru
After=network.target

[Service]
WorkingDirectory=/opt/badcom-zayavki
ExecStart=/usr/bin/node --env-file=.env zayavki.mjs
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

Затем `systemctl enable --now badcom-zayavki`.
5. В настройках nginx для сайта badcom.ru добавить передачу запросов сервису (сайт сам при этом остаётся набором статических файлов из папки `site`):

```
location /api/ {
    proxy_pass http://127.0.0.1:8787;
    proxy_set_header X-Forwarded-For $remote_addr;
    client_max_body_size 32k;
}
```

6. Проверка: открыть `https://www.badcom.ru/api/health`, должно быть «ok». Затем отправить тестовую заявку с сайта.

## Telegram и персональные данные

По умолчанию (`TG_FULL=false`) в Telegram приходит только номер заявки и район, без имени, телефона и адреса. Полные данные приходят на почту. Если включить `TG_FULL=true`, персональные данные будут передаваться на серверы Telegram за границей. Тогда нужно: добавить это в Политику обработки ПДн и в Согласие, подать в Роскомнадзор уведомление о трансграничной передаче и изменить сведения в уведомлении об обработке. Без этого включать не стоит.

## Почта

Почтовый ящик info@badcom.ru должен находиться у российского провайдера (на своём сервере, у Яндекса, Mail.ru и т. п.), иначе заявки с персональными данными окажутся за границей.
