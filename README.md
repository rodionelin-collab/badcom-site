# badcom.ru — новый сайт «Плохой Компании» (тестовая версия)

Страницы генерируются скриптом `build.py` в папку `site/`. Netlify запускает его сам при каждом обновлении.
Тарифы, контакты и тексты правятся в `build.py`.

## Юридические страницы
Тексты политики обработки ПДн (`/privacy`), согласия (`/consent`) и политики cookie (`/cookies`), а также баннер cookie лежат в `legal.py`.
Жёлтые пометки на страницах — данные, которые нужно заполнить до запуска (номер в реестре операторов ПДн, номера лицензий, локализация данных).
Счётчики аналитики и рекламы подключать только внутри проверки `window.badcomCookie.analytics`.
